# LDO3V3：近源布局与Flash负载审查

正式电气源保持[22600f2](https://github.com/isarmg/pcie-switch-2/commit/22600f2c9371c92934a09e4ea6fa4c95897cc041)，PCB SHA256 `e33bc9bf7cb41045c3171abd07677bc36ebe7c3960d61349e4ad5ba2437ecb3c`。本次仅归档审查，未改PCB、原理图、物料或电源架构，未上传失败PCB。仍97断网/94实装，先前原生检查结论未被本次文档修改冒称为新全检。

## 可以确认的结论
- C5111实际是0603，原值10µF6.3V、未选具体MPN。曾从庭院推断0805不正确；本次已用真实封装/pad确认。GRM21BZ71E106KE15L仅为0805设计验证候选，最大外形2.2×1.45×1.45mm；典型偏压表现不能保证全温度/低激励/老化联合有效容量。正式封装和高度不随研究修改。详见[选型研究](MLCC_REVIEW.md)。
- 有限0805竖列方案需要移动三只低速电阻及两枚既有深盲孔。左、右、错列三次预筛均产生真实内层冲突，停止该方案。三份拒绝DRC分别9、10、3错误；右侧10错中6项为内层冲突、4项为临时B面保留引线与未迁电阻产生的冲突，不能全部外推为最终布局不可能。未构建可接受的完整电容/电阻迁移方案。详见[布局审查](LAYOUT_REVIEW.md)。
- 精确Flash为W25Q80DVSNJG，Winbond Preliminary Rev.N官方表列读50MHz最大15mA、写状态/编程/擦除最大25mA。四只10k加一只100k上拉在3.45V全拉低时，标称合计1.4145mA；已知写/擦静态筛查总26.4145mA，低于TI外部30mA限制。没有证据证明必然超流，也不能称最差负载已通过。实际容差、I/O动态、启动和热条件仍需补齐。TI典型内部5.64mA不能证明总70mA最差上限。详见[负载审查](LOAD_REVIEW.md)。
- TI明确设计意图为LDO3V3给Flash及其上拉供电。不能因未完成的预算就改接无关AUX电源；同域启动、无电池模式与反向供电必须保留。Flash最低2.7V与LDO最低2.7V重合，尚无额外走线压降/瞬态余量证明。当前源、VDDIO、Flash供电及地仍断开，预算只是完成实际连接后的条件筛查，不代表板能启动。

## 独立核查范围
发布者确认正式源hash未变，复核三份拒绝DRC计数；直接读本地原厂Flash Rev.N原件，确认精确型号、电压和最大电流表，重复实际9器件域的native net/DNP/阻值清单与标称计算。重新读取MLCC规格和典型曲线，保持典型与保证边界；实时原厂URL重取受限，未冒称独立重新下载。上述拒绝样本未经过完整接受门禁，不作为已验候选。

## 下一步需要什么
先在明确范围内规划PD区低速信号的内层通道与器件布局，并取得板厂确认的叠层、成品铜厚、现有深盲孔与组装规则；保留全部高速和已有旁路回归。另需真实电容的联合有效容量/稳定性与Flash启动、动态及热预算。三次局部失败不证明整板所有重布局都不可能，也不支持继续无界塞孔。
