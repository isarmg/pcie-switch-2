# S06 x2：联合选择末端入口并硬预留扇出

## 结果

已修复前一轮的“先布路线占据后布 TX1 入口”问题：预先选择彼此兼容的端点扇出，并将其他通道真实 pin 到入口的完整 P/N 线段作为硬障碍。12 个有界方案全部完成，最好仍为 3/4 方向通道，完整 x2 尚未找到。

最好前缀是 RX0、RX1、TX1；第四条 TX0 的入口未被先前铜线占用，但在当前保守栅格与既定前缀下没有连通路径。该结果不能解释为 x2 不可能，也不能据此决定加层。

正式 PCB 和全部原孔未改。拟定 L7 信号面/L8 连续地参考只是架构要求，没有生成 24 层 PCB，也没有原生整板 DRC、连续参考地、阻抗、眼图或制造签核。

## 固定基线

- 源 SHA-256：`e33bc9bf7cb41045c3171abd07677bc36ebe7c3960d61349e4ad5ba2437ecb3c`。
- 同一份原板的全部 3,837 孔保守投影；源 XY、孔径、钻孔和跨度未改。
- 线宽、对内铜边距、其他网络铜边距均为 0.10 mm；网格 0.05 mm。
- 对中心线的孔额外膨胀 0.27 mm，其他导体中心线膨胀 0.32 mm，保持此前几何模型。
- 原其他内层铜线/电源铜没有带入新信号面；不能视为完整板的全部铜间距检查。
- 每次 A* 最多 1,200,000 展开节点；所有输出再做精确线段检查。精确不通过即拒绝，不放宽阈值。

## 候选和硬预留的范围

每通道使用 8 个目的端候选：y 偏移 `0, +0.10, -0.10, +0.20 mm`，乘以入口向左偏移 `0, 0.20 mm`。实体焊盘和过孔不动。源端使用同一个从真实 U1 pin 向东的固定模板，未探索源端方向或入口变化。

先分别核查 32 个候选的真实端点、完整两端 P/N 线段、全部原孔、对内间距和入口栅格净空。局部合法数为：RX0 2 个、RX1 2 个、TX0 6 个、TX1 6 个。非法候选也完整保留于 `ENDPOINT_PREFLIGHT.json`，另一个脚本独立重算了全部 32 个合法/拒绝标签。

局部筛选后共有 144 个四通道组合，全部通过局部互相间距与入口兼容性检查。按总入口位移最小排序只取前三个：

| 组合 | RX0 y 偏移 | RX1 y 偏移 | TX0 y 偏移 | TX1 y 偏移 |
|---|---:|---:|---:|---:|
| 0 | 0 | +0.10 | 0 | 0 |
| 1 | 0 | +0.10 | 0 | +0.10 |
| 2 | 0 | +0.10 | 0 | -0.10 |

这三组合的入口向左偏移均为零。其余 141 个兼容组合没有做长路线搜索。

每个方案只预留每通道选定的一组扇出，不封禁所有备选的并集。布当前通道时，排除其自身预留；其他三通道的源端和目的端完整 P/N 线段，按铜宽和间距连同拐角余量硬阻挡。已经放置的新长线也加入障碍。每次重新生成整组路线，没有实现方案内定位冲突后仅拆掉相关路线的定向 rip-up。

## 实际执行的 12 个方案

每组使用相同四个既定顺序，失败后停止该方案，首个完整成功本应立即结束全部搜索。本次没有完整成功，恰好执行上限 12 个。

| 文件序号 | 顺序 | 接受前缀 | 首个失败 |
|---|---|---:|---|
| 00 / 04 / 08 | RX0 → RX1 → TX0 → TX1 | 2/4 | TX0，当前保守栅格无路径 |
| 01 / 05 / 09 | RX0 → RX1 → TX1 → TX0 | 3/4 | TX0，当前保守栅格无路径 |
| 02 / 06 / 10 | RX1 → RX0 → TX1 → TX0 | 1/4 | RX0，精确几何拒绝 |
| 03 / 07 / 11 | TX1 → RX1 → RX0 → TX0 | 1/4 | RX1，当前保守栅格无路径 |

不存在“入口已堵住，零节点结束”的结果，说明已消除前一轮直接入口占用；这不表示所有剩余路线都可完成。

RX0 的精确拒绝还暴露出当前无方向状态 A* 的局限：它可能从错误方向进入目的端中心入口，接入固定扇出时折返。输出的 P 导体自交，P/N 铜边距为 -0.05357899 mm，N 到本对 P 端点孔铜边距为 -0.06300868 mm。独立局部扇出合法不保证任意方向接入都合法，完整输出的精确检查正确拦住了这一点。负值未被容忍或修饰为成功。

## 最好前缀的实际几何

取 `RESERVED_SCENARIO_01.json`，三个已通过的长段：

| 方向通道 | P mm | N mm | P/N 差 mm |
|---|---:|---:|---:|
| RX0 | 62.183579 | 62.055843 | 0.127735 |
| RX1 | 67.659667 | 67.550311 | 0.109356 |
| TX1 | 78.523781 | 78.670671 | 0.146890 |

最小跨通道铜边距为 **0.1329424324 mm**。TX1 电容后两根原 F.Cu 线各长 1.38 mm，因此 TX1 完整板内铜线长 79.903781 / 80.050671 mm。长度不含过孔垂直传播和电容内部传播，未作时延/偏斜验收。

lane 0 和 lane 1 的四根 AC 后段另行与原 F.Cu 焊盘、走线、前端过孔和保存填铜检查，最低铜边距约 0.349999 mm。AC 前后段不重复计作 lane。3/4 方向通道仍不构成完整 x2。

## 便携重放

需要 KiCad AppRun、Python + NumPy + Shapely，输入源 hash 固定。只读取 PCB，不调用 SaveBoard。

```sh
E1S_SOURCE=/absolute/path/Main_12E1S.kicad_pcb \
KICAD_APP=/absolute/path/KiCad/AppRun \
ROUTE_PYTHONPATH=/optional/absolute/path/dependencies \
./replay_reserved.sh /absolute/path/new-empty-scratch
```

`ROUTE_PYTHON` 可指定 Python 可执行文件。输出目录必须不存在或为空。脚本复制自身最小代码，在新目录用 KiCad 原生重新提取几何，再预检、路由和独立验证。没有读取其他研究目录旧几何的隐式依赖。

`validate_reserved_results.py` 不调用路由器的几何判定，另行对每个实际候选导体计算全部 3,837 孔、真实 pin 端点、P/N 间距、已接受跨通道间距、其他已选扇出预留及 AC 后段。它会验证失败标签；runner exit 0 表示证据计算完成，不表示 x2 已完成。

审阅图可在生成的输出目录中重画：将本目录 `render_reserved_geometry.py` 复制到输出目录，用带 matplotlib 的 Python 执行。图示不是几何检查。

提交范围仅脚本、小 JSON、README 和 PNG。不要提交大提取几何、缓存、ZIP 或伪装成完成设计的原生 PCB。

## 后续算法边界

端点方向约束、源端候选、冲突定位与定向 rip-up 尚未实现，本轮不能称这些空间已穷尽。若继续，应在同样工艺基线下作为独立有界算法试验；高端工艺/新孔拓扑属于另一组假设，不能悄悄缩小本轮线宽、间距或孔来覆盖失败。没有执行 x4、两个槽或每信号层 16 方向通道容量验证。

## 独立归档审查

“真实端点”在此指正式源文件的实际 pad 坐标和网络。U1 仍是虚构 PEX 球位，不能当作已验证真实芯片封装。独立审查另外从本次原生提取的几何重算全部 12 个方案的端点、原孔、P/N、跨通道间距、自交与板边，结果见 INDEPENDENT_SCENARIOS.json。
