# RTCRST 有界只读可行性
基线为已发布f7a11f8395f89a8cf62539c9f4f2b3c7325e8fc8373e40ed50a71f843a32ea32。本包无PCB候选、无器件/铜/metadata修改。

H15=RTCRST#；现R710 100k、C709 100nF RC reset draft。Intel829568-004 §16.1/16.2 pp143–144要求RTC有效供电时RTCRST保持高、仅G3清CMOS例外，并禁止与SRT直接短接。所核公开文本未给100k/100n指定值；只能称现有名义RC约10ms，不是阈值/漏电/释放时序保证。

B右侧近球区被C5222–26及U510占位，下沿被U504和Y701庭院夹住。F64连接器间隙可以放两RC，但当前RTC网没有F层电源入口，完整方案需reset和RTC电源两普通孔。
在一次获准的两孔预筛中，reset区x63–68/y30–36仅有x67.975/y30.50–30.60的0.45/0.25物理机会，尚未进行plane/路由验证。RTC电源的局部窗口x64.35–64.85/y36.05–36.55，在全层实际铜、全部实体焊盘含NC、75µm净距及1µm计算余量下，0.60/0.30与0.45/0.25两种普通孔连续可用面积均为0。

具体点(64.7,36.25)到既有In26 S10_SW_RX0_N铜最近仅0.06138mm，小于0.45孔所需0.30mm中心至铜距离；还受In16 TBT_DP_AUX_P限制。精确UUID见POWER_POINT_BLOCKERS.json。该阻碍为真实物理碰撞，不是单纯参考投影假设。
按边界停止，不再换孔位、加微孔、迁高速或铺长高阻线。R710/C709仍未接通，不声称RTC复位时序完成。屏幕外其它布局未经穷尽，本结论只覆盖所记录的最小方案。

READONLY.json含官方球位行/hash、原生net/地簇、两个孔型筛查结果。本次归档原始报告与发布者独立重复筛查结果；研究脚本及Base板副本不随本次文档提交。本轮没有DRC或all-plane通过候选可供合入；只有拒绝证据可归档。
