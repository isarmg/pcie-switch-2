# 24 层候选执行约束补充

状态：仅用于架构/几何实验与资格门定义，未生成或修改 24 层 PCB；未获得板厂签核。与 `REPORT.md` 基准源和证据一起使用。

## 一、五个门分开报告，不能把 UNKNOWN 写成 PASS

| 检查门 | 现在能做什么 | 缺板厂参数的影响 |
|---|---|---|
| 架构算术 | 24 层、12S/8G/4P、镜像、S 邻 G、候选连通图 | 可以检查，不受阻 |
| 探索性几何 | 假设性走廊/逃线、投影相交、同层差分策略、拥挤度与保留网表 | 可以运行，必须标注假设和覆盖范围 |
| 耦合资格 | 实际叠层/频变材料下的阻抗、串扰、回流、过孔与通道模型 | 缺实际材料/几何/限值则 BLOCKED |
| HDI/板厂工艺资格 | 各孔型、填孔、顺序压合、背钻、注册及可靠性工艺 | 缺项目签核则 BLOCKED |
| 生产释放 | 真器件、完整连通/DRC、机械、SI、PDN/热、DFM、装配与可靠性 | 相关门全部通过前 BLOCKED |

`24L_PLAN_CONSTRAINTS.json` 记录这五类 gate 的边界。计划文件合法、架构算术通过、几何实验找到路线，都不能自动更改 `fabricator_approved`、`si_qualified` 或 `execution_enabled`。

## 二、三个邻接 S–S 区不是额外屏蔽层

24 层功能序列：

S G S P G S S G P S G S | S G S P G S S G P S G S

三个 dual-stripline 区：

| 信号层对 | 各自最近 GND 参考 | 必须审的结构 |
|---|---|---|
| L6 / L7 | L5 / L8 | G5–S6–S7–G8 |
| L12 / L13 | L11 / L14 | G11–S12–S13–G14 |
| L18 / L19 | L17 / L20 | G17–S18–S19–G20 |

这里是两层分别使用同层 edge-coupled P/N 的信号组。**本方案禁止把同一差分对 P、N 分别放在两邻接 S 层**，因为这样改变了选定的传输线拓扑、参考环境和过渡设计。该禁令是本方案策略，不是声称有正确模型和工艺的 broadside differential transmission line 在物理上永远不可行。

[Intel AN958 §5.1.2](https://cdrdv2-public.intel.com/677286/an958-683073-677286.pdf) 对 dual-stripline 给出定性方向：邻接信号层优先正交、拉大 S–S 距离、拉近 S–G 距离。这个一般指南不是本 CPU/PEX 的 PDG，也没有给本板可直接采用的 PCIe 5.0 串扰合格阈值。

因此，几何规划应：

1. 给每个邻 S–S 区设不同主方向，优先近 90° 交叉，避免两层同向长干线 broadside 重合。
2. 若两个相邻层都必须沿板长方向走 PCIe 干线，先用 XY 走廊错开或将一组迁至有 G 平面隔开的信号层，不把正交口号强行应用于不可避免的长平行段。
3. 对逃线、弯角、等长蛇形、器件焊盘与连接器扇出逐段检查。主方向“X/Y”并不覆盖这些局部耦合。
4. 将 S–S 间距与 S–G 间距交给真实叠层和求解器共同优化。不给固定“3 倍/5 倍”当通过线，不先冻结 1.6 mm，也不假设两层之间有屏蔽铜。
5. 参考地必须检查实际填铜轮廓、antipad 和岛/缝隙。GND 同名、zone 外框覆盖或某个 GND via 靠近，都不是完整回流的证据。

### 可机检记录

对 L6/7、L12/13、L18/19 上不同网络之间的相互作用，记录：

- 两个 net、layer、segment/pad UUID；最小 XY 边缘距离
- 交叉锐角、近似平行段的投影重叠长度、实际 Z 间距
- 该宽度/间距/材料/接口适用的 SI 合格 envelope ID
- 通过/超限/缺数据；若有局部例外，必须绑定有限区域、几何版本及批准证据

“附近”的距离阈值、允许平行长度、交叉角公差和层间距离必须来自合格 envelope。参数尚未提供时，可以完成投影重叠清点和几何比较，但不能签出“低串扰已通过”。

## 三、L1 到 L3 跨两个 buildup 的中间 GND 层问题

`2+20+2` 仅是候选工艺族。激光 buildup 层数、压合次数、激光孔参数均未确认，不得由层数自动推出可加工性。

顶面信号从 L1 进入 L3，在候选短 HDI 路径中需要两个独立互连阶段：L1–L2 和 L2–L3。L2 虽为 GND 角色，但信号微孔的 landing 是该信号网的铜盘，必须通过 antipad 与 GND 隔离，绝不能把它接入地面。

有两种待评审几何：

- 错位：两孔不同 XY，在 L2 用短、局部、同网 landing bridge 连接。必须满足偏移、孔/盘间距、注册及填孔规则，同时测出 L2 地平面被削掉的区域。该桥只能在登记的逃线区域内，不能把 L2 变成通用信号布线层。
- 堆叠：两孔同 XY，要明确内部孔先成孔/镀铜/填铜/整平，再形成上级孔的顺序、target/capture land、cap/wrap、界面及回流可靠性。不能因为两个短 via 层对都“允许”，就自动合成为批准的 stacked macro。

底面 L24–L23–L22 完全同理。L23 上的中间信号 landing 也必须隔离。单个 L1–L3 skip via 是第三种不同工艺，不等价于两级短微孔，不允许脚本静默替换。

[NCAB 微孔结构指南](https://www.ncabgroup.com/microvias/)与[HDI 技术指南](https://www.ncabgroup.com/hdi-high-density-interconnect-pcb/)用于提醒这些工艺限制；具体本项目仍要厂家确认，不能以官网示例替代签核。

## 四、907 个深盲孔的分区替代队列

`DEEP_VIA_REPLACEMENT_QUEUE.csv` 包含原始 907 个 UUID，均为 `UNASSIGNED`，不附自动旧层→新层映射。

| 网名初筛类别 | 孔数 | 先评估的路线 |
|---|---:|---|
| PCIe/高速串行 | 608 | 成对规划近侧逃线和有参考面的干线；必要时批准的机械孔/背钻或完整 HDI+core macro |
| 参考时钟 | 68 | 同层差分、过渡对称、专用回流；沿真实时钟树验证，不用长 blind 省工 |
| USB2/AUX 等其他差分 | 20 | 按各接口真实时序/阻抗规划，不当 PCIe 同一模型 |
| 控制/模拟/尚未分类 | 209 | 优先近侧外层或近侧 S 层；先区分 sense、晶振和快边沿控制，不把全部视作低敏感网络 |
| GND | 1 | 接近侧 GND，再经批准的地互连结构连接所需参考面 |
| 电源 | 1 | 经 PDN/热核算的铜面和孔阵列，保持 net 身份 |

这些是正则匹配网名的初筛，不是器件/网表已核验的分类。正式 routing 必须绑定已验证的接口、P/N 配对、端点与 pin map。

分区策略：

- 同侧器件之间，优先消除不必要的跨板深度，让控制和可用的高速路径留在近侧经批准层组。
- 深层高速路径可研究机械通孔加单/双面背钻，但孔径、焊盘、背钻直径及避让会比现有 200/100 µm 小孔更占位置，必须先做 BGA/连接器扇出实验。
- 候选核心 L3–L22 埋孔如果在 L6 或 L19 等中间层引出，仍有 unused barrel；不能因“buried”名称就当作无 stub。核心背钻也不是默认能力。
- HDI 叠到核心孔上需要整个组合的签核，不是每只 via 分别过 DRC 即可。若工厂不接受，应重新分配逃线、使用错位 macro 或改变架构，不能默认增加第三/第四微孔堆叠级数。
- 当前 1,609 个 L29→L32 地孔是另一批明确改善对象。新架构把底面最近参考地设为 L23，有机会缩短局部地引出；其余各 GND 面之间仍须建立真正的回流连接，不能批量改孔后省略连通检查。

[TI SNLA426 §19/23/24](https://www.ti.com/lit/an/snla426/snla426.pdf)支持连续参考、匹配过渡、短 stub 和背钻评估的方向，但其示例尺寸/阈值不是本板厂或该 CPU/PEX 的已批准参数。

## 五、需要板厂和设计方共同提供的字段

机器模板 `FAB_INPUT_TEMPLATE.json` 把 35 项输入全部置为 `null`，并附 owner、单位、说明、source/revision/status。null 不是零、无限制、免检或已批准；选择不使用某项工艺时，需要有证据的正式“不适用”记录。

主要分组：

1. 板厂实际生产场地、项目 stackup 编号/版次、材料/core/prepreg/压合、24 层铜和 23 个介质间距的厚度/公差、频变 Dk/Df/粗糙度、对称及铜平衡约束。
2. 最终板厚与机械批准；层级线宽/间距/蚀刻、公差和注册。
3. whole via macro：所有物理钻孔跨度、机械/激光入口与目标孔径、pad/antipad、孔深/纵横比、填铜/盖帽/平整度、错位/堆叠规则、压合钻镀顺序、落在 GND 层的孤立 signal landing。
4. 埋孔跨度、可否核心背钻、背钻面/孔径/深度/停止定义/残 stub/避让；via-in-pad 装配要求。
5. 铜孔/微孔的回流与可靠性 coupon、裸板连通/阻抗测试及验收证据。
6. 设计方真实 ball map、PDG、接口分类、每层阻抗 profile、耦合 envelope、回流 corridor/macro、通道预算和 PDN/热约束。

单独缺少参数并不阻止继续做架构算术、走廊分配、假设性逃线和成对几何实验。它只限制相应资格判断；结果必须清楚标记“几何候选”“待工艺/耦合验证”。
