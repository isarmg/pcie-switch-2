# S06 x2 方向状态路由：修复末端折返，仍未完成四通道

## 结论

旧 RX1 先行、RX0 随后时，RX0 接近末端又反向拼接，造成 P 自交、P/N 相交并碰到本对另一端点孔。本版将进入方向加入搜索状态，固定端口方向、保留 P/N 次序，并显式构造未经自动裁剪的偏移线。

同样三个入口组合、四个顺序，共 12 个正式方案已完成。原来 02 / 06 / 10 的 RX0 失败已修复，接受前缀由 1/4 提升为 3/4。27 个实际生成的完整候选通道均通过独立全孔、真实端点、P/N、跨对及预留扇出精确检查。最后仍没有完整 x2：各方案剩余通道均在当前前缀和保守栅格下不连通。

**本轮证明的是末端算法缺陷得到修复，不是整板容量或 SI 已通过。** case 02 的 RX0 因绕行，P/N 长度差达到约 1.424 mm，尚未做偏斜补偿。

## 算法修复

1. 搜索状态是栅格坐标、进入方向、已走直线步数。入口前已有向东固定线段，目的端必须向东到达且至少已直行四个栅格步。P/N 物理端点和左右次序不互换。
2. 相邻转向最多 90°，禁止 135° 和 180° 转向。两次转向之间至少四个栅格步，轴向为 0.20 mm，斜向更长。
3. 只压缩同方向共线点，不再使用会改变端口切向的远距离直视简化。
4. P/N 用显式相邻偏移支撑线的 miter 交点构造。没有调用 `offset_curve` 自动删除环、自交或断片。偏移本身若自交直接拒绝；接上真实 pin 扇出后还要检查完整两根折线的自交、互交及全部铜距。
5. 主走廊不再豁免本对端点孔；实际 pin 连接由固定扇出完成。目的端扇出位于 gateway 后侧的区域也作为自身屏障，防止为了调整到达方向而绕入自己的末端铜线。没有移动孔或缩小避让。
6. 每次方向状态 A* 最多 1,200,000 展开状态。先做四连通分量检查，再用 SciPy 的二维栅格最短距离场引导方向状态搜索。距离场放松了方向约束，不放松栅格孔/线障碍和禁止切角规则。启发权重为 1.5，每次转弯另加 0.2 个栅格代价单位，所以不宣称路径全局最短。

四连通预筛之所以可用于本栅格：一个允许的对角步要求相邻两个正交格都空闲，因此任何本模型允许的八邻接路径也能改写成四连通路径。该预筛只证明**本保守栅格、已选端口和已布前缀**不连通，不能证明连续几何无解或全局 x2 不可能。有限的方向/直段约束也会限制可搜索空间。

预计算的二维图固定为 1,921 × 901 格；1,200,000 上限专指方向 A* 展开，不包含编译库对二维距离场的预计算。

## 回归和独立检查

- `REGRESSION_OLD_RX1_THEN_RX0.json` 保留原失败原貌：末端方向余弦 -0.98386991，P 自交，P/N 铜边距 -0.05357899 mm。
- `test_directed_ports.py` 验证旧失败可复现、U-turn 被拒绝、显式 90° miter 无自交且保持间距、只允许向东到达、反向唯一通道不会错误接入，以及新 case 02 的完整 RX1/RX0 实际几何通过。
- `validate_reserved_results.py` 不使用路由器的几何判定，重新计算全部原孔、真实端点、对内/跨对/预留线距及 AC 后段，确认 32 个局部扇出候选和 12 个方案的所有成功/失败标签。
- `validate_direction_properties.py` 独立求相邻偏移支撑线的交点，逐点重构全部输出 miter，核查首末方向、转角和完整折线，确认没有自动裁剪。
- `DIRECTION_UNIT_TESTS.json`、`RESERVED_EXACT_CHECKS.json`、`DIRECTION_INDEPENDENT_CHECKS.json` 保存机器结果。

## 可重放

依赖：KiCad AppRun 原生 Python、主机 Python 的 NumPy、Shapely、SciPy。实测版本 NumPy 2.5.4、Shapely 2.2.0、SciPy 1.17.0。

```sh
E1S_SOURCE=/absolute/path/Main_12E1S.kicad_pcb \
KICAD_APP=/absolute/path/KiCad/AppRun \
ROUTE_PYTHONPATH=/optional/absolute/path/dependencies \
./replay_directed.sh /absolute/path/new-empty-scratch
```

`ROUTE_PYTHON` 可选择 Python 可执行文件。脚本拒绝非空输出，在新目录重新原生提取本次输入几何；没有读取兄弟研究目录旧几何的隐式依赖。先跑单测，再跑正式 12 个方案和两个独立验证器，最后补实际回归断言。exit 0 表示计算和验证完成，不表示 x2 成功。

审阅图用 `render_direction_geometry.py`，放入重放输出目录后以带 matplotlib 的 Python 执行；图不是几何判定器。轻量发布仅含代码、JSON、README 和 PNG，不含原生大几何、缓存、ZIP 或候选 PCB。
