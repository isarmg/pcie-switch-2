# S06 同层差分联合布线：x1 成功，x2 有限搜索边界

## 结论

在原 96 × 45 mm 板框、真实文件焊盘/网名与全部 3,837 个原孔的保守投影模型下，**S06 一个完整双向 x1 lane 的 TX0/RX0 已在同一拟定信号层 L7 找到通过精确解析几何检查的路由**。要求相邻 L8 是连续 GND，但本试验没有建立或验证该地面。

关键改进是联合重布的顺序：原来先走 TX0 最短路径再求 RX0 会失败；先 RX0 再重新求 TX0，则两方向均通过。原来的失败不能被解释为“一个 x1 不可能在同层布通”。

向同槽 x2 的四个方向通道扩展后，初始六个顺序最好通过 2/4；只把 RX1 成对末端走廊下移 0.10 mm、保留原孔与间距，再补四个既定顺序，最好通过 3/4。**完整 x2 尚未证明，3/4 成功前缀不能算完整 x2。** 搜索在这里停止，没有扩大到 x4、两个插槽或每层 16 个方向通道。

没有修改正式 PCB、没有层号映射、没有删改原孔、没有生成 24 层候选板。本结果不是 KiCad 原生整板 DRC、连续回流、阻抗、SI、制造或通道容量最终签核。

## 输入和假设

- 源 SHA-256：`e33bc9bf7cb41045c3171abd07677bc36ebe7c3960d61349e4ad5ba2437ecb3c`
- KiCad 10.0.7 原生只读提取：32 个源铜层、9,065 段原线、3,837 个过孔、7,120 个焊盘。
- 所有原孔的 XY、直径、钻孔和原层跨度均未更改；原生检查确认这些孔没有分层直径变化。
- 所有原孔均保守投影到拟定信号面，包含实际可能不延伸到该面的旧盲孔。
- 线宽、P/N 对内铜边距、其他网络铜边距均假设为 0.10 mm；这不是受控阻抗参数。
- 中心线孔障碍额外膨胀为 0.27 mm；已放新导体中心线膨胀为 0.32 mm，包含对宽、其他网络间距和拐角余量。
- 新走廊不保留原板其他内部信号线/电源铜；只有原孔、真实端点和新候选之间的几何障碍。因此不能外推整板连通或全部铜间距。
- 保留的 AC 后段在原 F.Cu 上，另行与原 F 面焊盘、走线、过孔及保存填铜检查。电容前后是同一个方向通道的两个网段，不重复计 lane。

## 同层 x1 成功结果

`SCENARIO_01.json`：先 S06_SW_RX0，再重新求 S06_SW_TX0。两方向均拟定为 L7。

| 长段 | P mm | N mm | P/N 差 mm |
|---|---:|---:|---:|
| RX0 | 62.183579 | 62.055843 | 0.127735 |
| TX0 | 80.853756 | 81.027535 | 0.173779 |

TX0 电容后原 F.Cu 两根线各为 1.38 mm，所以完整板内 TX 铜线为 82.233756 / 82.407535 mm。长度不含电容内部和过孔垂直传播，不是协议偏斜验收。

- 两个方向通道之间最小铜边距：0.32341784 mm。
- 每个 P/N 对的最小铜边距：约 0.100 mm。
- 新线到其他原孔的最小铜边距不小于约 0.120 mm。
- 相比独立平面单路 TX0，联合 TX0 增长约 6.32 / 6.35 mm，换取同层可行走廊；并非把两条旧路线叠到同一层。
- 完整 x1 = 两个方向差分通道、含 AC 前后共三个差分网段。

## 明确的有限搜索范围

网格固定为 0.05 mm，每次通道搜索最多 1,200,000 个展开节点。精确线段检查不通过时，不降低间距或接受碰撞。每个多通道方案在首个失败处停止；不把未尝试通道标成成功。

x1 预声明最多两个顺序乘四种代价，但默认在首次同层精确成功时停止。本次实际只执行两个单位几何代价顺序：

1. TX0 → RX0：失败，作为旧固定顺序基线。
2. RX0 → TX0：成功，进入 x2。其余代价模式未执行，不能说已比较。

x2 首轮固定六个顺序：

| 文件序号 | 顺序 | 成功前缀 |
|---|---|---:|
| 00 | RX0 → TX0 → RX1 → TX1 | 2/4 |
| 01 | RX0 → RX1 → TX0 → TX1 | 1/4 |
| 02 | RX1 → RX0 → TX1 → TX0 | 0/4 |
| 03 | RX1 → TX1 → RX0 → TX0 | 0/4 |
| 04 | TX1 → RX1 → TX0 → RX0 | 1/4 |
| 05 | RX0 → TX1 → RX1 → TX0 | 2/4 |

首轮 RX1 的固定扇出模板在原 GND 孔 `(57.318794, 22.5588)` 附近只留下 0.0412 mm 铜边距，被精确检查拒绝。后续只将 RX1 的成对末端走廊向 y 增大方向移 0.10 mm；孔未动、线宽/间距未降。使用独立脚本 `repair_rx1_escape_trial.py`，初始脚本默认偏移仍为零，可复现原失败。

补试最多四个已声明顺序，全部执行后停止：

| 文件序号 | 顺序 | 成功前缀 |
|---|---|---:|
| 00 | RX0 → RX1 → TX0 → TX1 | 3/4 |
| 01 | RX1 → RX0 → TX1 → TX0 | 1/4 |
| 02 | RX1 → TX1 → RX0 → TX0 | 2/4 |
| 03 | RX0 → TX1 → RX1 → TX0 | 2/4 |

## 最好 x2 前缀和第四条的确切阻挡

`X2_REPAIR_SCENARIO_00.json` 中前三条均通过：

| 方向通道 | P mm | N mm | P/N 差 mm |
|---|---:|---:|---:|
| RX0 | 62.183579 | 62.055843 | 0.127735 |
| RX1 | 67.659667 | 67.550311 | 0.109356 |
| TX0 | 82.330631 | 82.472221 | 0.141589 |

这三个通道之间的最小铜边距为 **0.13294243 mm**，其 P/N 对内最小铜边距仍约 0.100 mm。

最后的 TX1 在预设末端中心线入口 `(63.6, 22.85)` 被已生成的 TX0 走线阻挡：距 TX0_P / TX0_N 中心线分别为 0.20842346 / 0.00842346 mm，小于本模型 0.32 mm 中心线排斥包络。因此没有开始新的 A* 展开。

这个直接阻挡来自**本轮新走线**，不是一颗直接压在入口上的旧孔。旧孔分布可能限制此前路线的选择，但不能把这次失败简化为“必须再加层”或“旧过孔本身不可解决”。未来允许重做过孔/逃线宏后，需要另一个明确工艺模型；当前证据仍原样保留。

## 后续边界

本轮条件和失败已冻结。后续用户要求的高端工艺应建立新的、可由同一板厂共同制造的线宽/间距、孔、介质和叠压假设，再重新规划逃线；不能悄悄缩小本轮参数来覆盖失败。真实 PEX 球位和封装 escape 仍未证，当前 3,837 个旧孔不应自动成为最终拓扑，但这不赋予任意孔结构制造能力。
