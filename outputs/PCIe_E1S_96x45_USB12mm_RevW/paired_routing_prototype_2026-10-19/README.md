# E1.S 差分同层成对重布：独立几何试验

## 结论

已完成一个有代表性的完整 S06 x1 lane 板内几何试验：TX 和 RX 共 2 个方向差分通道；TX 含耦合电容前、后两段，共 3 个差分网段、6 根导体。两条长通道各自的 P/N 都重新从共同中心线生成、保持同一信号平面。没有把旧走线改 layer index 冒充重布。

- TX0 长段暂分配到新 24 层方案的物理 L7，连续 GND 参考要求为 L8。
- RX0 长段在独立平面试验中暂分配到物理 L18，连续 GND 参考要求为 L17。
- 不使用相邻 L6/L7 承载这两条长距离同向线路，避免把这一试验进一步引入未经验证的宽边耦合风险。
- 所有 3,837 个原过孔的位置、钻孔和原层跨度均原样保留，作为保守障碍投影；不增加孔，不删除源连接。
- 没有修改、保存或替换源 PCB，没有生成 24 层 PCB，没有 Git 修改/提交。

这个结果只建立了局部空白信号平面的几何可行性。原板其他信号线和电源铜必须重新规划，未作为该空白信号平面的旧铜保留。**不能宣称整板 DRC、24 层可布通、16 对/层容量、连续回流参考、阻抗或制造已通过。**

## 完整试验范围和结果

TX：U1 AH3/AJ3 → C4041/C4042 pin 1；经两个独立电容器件；C4041/C4042 pin 2 → J6 B18/B17。

RX：J6 A18/A17 → U1 AH5/AJ5。本板该方向没有单独板内 AC 元件段，不凭空添加卡端电路假设。

几何假设为线宽 0.10 mm、P/N 对内边距 0.10 mm、其他网络边距 0.10 mm；单对铜宽 0.30 mm，连同两侧 0.10 mm 间隙需要 0.50 mm 直走廊。这不是受控阻抗参数。

| 段 | P 长度 mm | N 长度 mm | 差 mm |
|---|---:|---:|---:|
| 原 TX 电容前 | 114.455 | 117.555 | 3.100 |
| 新 TX 电容前 | 74.532 | 74.679 | 0.147 |
| 原样保留 TX 电容后 F.Cu | 1.380 | 1.380 | 0 |
| 新 TX 总铜线，含电容后段 | 75.912 | 76.059 | 0.147 |
| 原 RX | 104.835 | 106.435 | 1.600 |

这些长度不含电容封装内部路径和过孔垂直路径；没有给出或通过任何协议时延/偏斜门限。任意角度和拐角尚未按板厂或 SI 约束优化。

- 新长段为同层平行偏移几何，精确线段距离复核最小 P/N 铜边距约 0.100 mm。
- 新长段距其他原过孔的最小铜边距约 0.120 mm；全孔保守投影的精确碰撞数为 0。
- 四根长导体都连接真实网名的原孔及实际端点焊盘；端点与 pad center 的差不超过 0.000001 mm。
- F.Cu 两根电容后段原样保留。按实际 F 面焊盘包围盒、原走线、实际延伸到 F 面的过孔和已保存填铜检查，最小其他铜边距约 0.350 mm，没有 0.10 mm 检查碰撞。
- 地参考为规划要求，未填充新地面、未证明电气连续性，也未验证换层附近的回流孔。

## 扩展为何停在这里

先完成 TX0 后，把它作为铜障碍加入同一个试验平面，再试 RX0：

1. 东向端点扇出：0.05 mm A* 网格、全孔投影以及中心线 0.27 mm 包络下没有找到通路。
2. 西向扇出：端点被这一保守障碍集合阻挡。
3. RX0 独立平面主干有路；初版末端斜扇出撞到两颗原 GND 孔。将末端改成同层平行短直段再在原信号孔处展开后，精确几何检查通过。

固定首路、固定端点扇出和离散网格的失败只是有界搜索失败，不是数学上的不可布通证明。没有尝试通过移动/删除原孔、删除源网络或降低间距消除失败。两条通道在不同平面的成功也不证明“每层容纳两个 x4 插槽的 16 个方向差分通道”。

裸直线总宽估算（尚未包含端点逃线、过孔、连接器阻挡、地参考和电源）为：16 对、对间边距 0.10 mm 时 6.50 mm；对间边距 0.30 mm 时 9.50 mm，均含外侧两条 0.10 mm 间隙。这只用于后续走廊预算，不是串扰合格间距。

## 不能放行的项目

- 24 层整板重布、全部铜和全部网络连通/间距；当前根本没有一个可运行整板 DRC 的新 24 层候选。
- 16 对/层密度，以及两个 x4 插槽完整组的共享走廊。
- 新 24 层板的铜厚、介质、叠压、盲埋孔工艺与孔跨度。保存的原孔仍引用原 32 层结构，不能直接拿去制造。
- PEX 的实际球位图和厂商 escape。当前 U1 焊盘只是文件中真实存在的位置，实际器件球位仍是虚构的。
- 连续地参考、换层回流、过孔 stub、阻抗、损耗、串扰、眼图、PI 和热。

下一步应联合规划至少一组两个 x4 插槽的 16 个方向通道，包括端点逃线及全部其他铜/地/电源约束，再决定 24 层目标是否具备实际容量。具体层厚和孔结构必须由真实物料和板厂工艺输入后另行验证。

## 便携重放

设置实际源 PCB 和 KiCad 10 AppRun，再提供一个空的输出目录：

```sh
E1S_SOURCE=/path/Main_12E1S.kicad_pcb KICAD_APP=/path/AppRun \
  ROUTE_PYTHONPATH=/path/numpy-and-shapely \
  bash replay.sh /new/scratch/output
```

路由 Python 需 NumPy/Shapely 2，绘图 Python 需 matplotlib；可用 ROUTE_PYTHON / RENDER_PYTHON 指定解释器。依赖已安装时可省略 ROUTE_PYTHONPATH。E1S_RENDER=0 可跳过图，但不跳过几何检查。脚本拒绝非空输出目录，复制最小代码后只读提取当前源；计算仅使用该次提取的几何，无兄弟目录缓存依赖。

发布者用官方 KiCad 10.0.7 在另一全新 scratch 独立重放，所有几何/检查结果与冻结交付一致（只排除运行耗时）。另写独立算法重查四个长线的真实端点集合、线长、P/N 最小间距、全部原孔投影和板边，见 INDEPENDENT_CHECK.json。没有在新 24 层工程运行原生 DRC，因为不存在这样的候选。
