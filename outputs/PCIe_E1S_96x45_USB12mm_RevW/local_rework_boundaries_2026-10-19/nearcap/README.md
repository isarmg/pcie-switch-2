# AN20近端旁路只读结论
源为已发布f7a11f83，无PCB候选或metadata修改。
C917原100nF 0402、C918原4.7µF 0603均仍远离CPU；未找到公开Intel材料对这两个精确容值的肯定要求，保留原草案值。
F侧J5/J6夹缝可容竖放C917，但AN20附近限定窗口无0.60/0.30或0.45/0.25普通贯孔可用，连续几何可用面积均0。借J6.A6已有F–In1地锚虽与CPU主地同簇，最近In1至In28地贯孔在(64,39.5)，距AN20约10.827mm，不能据器件几何靠近宣称短返回回路。
B侧必须退出CPU courtyard，最短先行距离已6.259mm再加电容半尺寸，不满足本轮真正近端旁路目标。
不迁C917/C918、不增加孔，保留实际动态PDN缺口。精确原生坐标/网表/回流锚及有限筛查域见FEASIBILITY.json和VIA_SCREEN.json；screen.py/report.py可复核。未声称所有全局重布局均不可能。

后续若要改善，需要CPU/PD器件区域协同重布局，重新安排真实近端电源与地转换、核定叠层/成品铜厚/普通孔与现存深孔制造工艺，并重新做完整参考与功能pad门禁；本次没有穷尽全板布局，也不授权制造。

本次发布仅归档报告，不包含研究脚本、Base板副本或候选板。发布者独立重复两个孔型窗口筛查，结果见INDEPENDENT_VIA_SCREEN.json。
